# 讃美歌スコアプレイヤー（試作）

画像・PDFをブラウザ内で処理し、音符候補の確認・編集、合成音での再生、MIDI出力を行う静的Webアプリです。Audiverisや変換サーバーは使いません。入力ファイルをアップロードする通信処理はありません。PDF表示時のみPDF.jsをjsDelivrから取得します（ネット接続が必要）。

## 起動

Node.js 24とPython 3で実行できます。依存パッケージのインストールは不要です。

```sh
cd /workspace/scorePDFtoPlay
npm test
npm start
```

HTTPサーバーから `index.html` を開いてください。ES Modulesを使うためファイルの直接オープンには対応しません。

## 使い方

1. 画像またはPDFを選択。PDFはページ番号を変更して「ページを表示」で切り替えます。
2. 調号を指定して「五線・音符を解析」。
3. オレンジ色の検出候補と右側の一覧を確認します。音程はMIDI番号（中央ド=60）、開始拍は0始まり、長さは四分音符=1です。
4. 誤検出を×で削除し、五線上のクリックで不足音を追加。追加音の開始拍は近くの候補から仮設定されるため修正してください。
5. 音程・開始拍・長さを修正して再生。MIDI保存で他の音楽ソフトに渡せます。

「操作デモ」は用意した6音で編集・再生・保存を試す機能です。楽譜認識のデモではありません。

## 認識の範囲と制約

- 水平で鮮明な五線の投影検出と、黒い音符の密度と白い音符の楕円輪郭に基づく候補検出です。機械学習モデルや汎用的なOMRはまだ組み込んでいません。
- 五線は上からト音・ヘ音の交互と仮定。単独の旋律譜や異なる段組みでは音程が誤ります。
- 調号はなし・♭1・♭2・♯1。調号を変更したら再解析してください（編集結果は置き換わります）。
- 白い音符は内部の白さと楕円輪郭から検出し、符幹の有無から二分音符（2拍）・全音符（4拍）を仮判定します。五線が内部を横切る場合は五線の画素を除外します。符幹が薄い画像や隣接する音符・記号では誤判定するため、長さの確認が必要です。
- 付点、臨時記号、休符、連桁、タイ、拍子、繰り返し、声部分離、歌詞の自動認識には未対応です。音符以外の記号を誤検出する場合があります。
- 開始拍は各五線で0から、横位置の近い候補を同時刻として仮配置します。下の段への時間の連結も手動修正が必要です。
- 画像は最大幅1500pxに縮小します。傾き補正や写真の歪み補正はありません。
- まだ提示された讃美歌画像での精度を実測できていません。合成五線画像で検出処理を検証しています。譜面通りの自動再生を保証する段階ではありません。
- MusicXML出力は今後対応予定です。現状の出力はMIDIのみです。

## GitHub Pages

このファイル群を `main` にpushし、リポジトリの Settings → Pages → Source を **GitHub Actions** に設定します。付属の `.github/workflows/pages.yml` がテスト後、公開に必要な4ファイルだけをデプロイします。サブパスでも動く相対URLを使っています。

この作業ではpushや実際のPages公開は行っていません。

## 検証

`node omr.test.js` で合成画像の五線・音符候補、音程計算、MIDIヘッダーとイベントを検証します。Chromiumでも画像読み込み→候補検出、操作デモの編集・削除・再生・停止・MIDIダウンロードを確認しました。PDFのCDN取得とPDFページ描画、実際の讃美歌の認識精度、公開先での動作は未検証です。
